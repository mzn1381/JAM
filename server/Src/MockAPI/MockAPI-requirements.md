# MockAPI Requirements

Implement a separate project called `MockAPI`, which contains mocks for APIs that will be called in the future by the AI team.

## Requirements

- API responses should generate random but convenient results.
- Use regex-based generators or other mock-data libraries where appropriate.
- The implementation should be designed in a way that can be replaced by the real APIs in the future.
- The source code can reside in `/Server/Src/MockAPI`.
- Using a framework is mandatory.
- Swagger documentation for these APIs should be implemented well so that other development teams can use it easily.
